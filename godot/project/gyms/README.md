# How this folder is normally used

"It's checked into the project's version control system so other team members can test it and give feedback. Once everyone agrees the feature is solid, it gets refactored and properly implemented following the project's coding standards. Otherwise, it can be deleted safely."

Read more at: https://www.gdquest.com/library/modular_game_architecture/

# How the implementation differs in this project

Since this is available for everyone to edit rather than an assigned team, it would quickly become unsustainable to commit everyone's test files. Thus, gyms will always be empty, as any other files are ignored. All in all, you can use this folder however you would like to.
