# Whitelist

Don't delete words from whitelist.json, replace them with "" so the indexes corresponding to each word are consistent across updates.

When adding new words, you can either add it to the end of the array, or you can replace an empty string ("") with the new word.

There's probably better ways to handle this, as this is my first time making a public GitHub repository. For now, this is the simplest method I could come up with, and I will take suggestions when I'm not busy.

Most of the words came from first20hours/google-10000-english, which is a really useful GitHub repository.
